## 一、章节核心要点（问题→机制）

1. **定位**：极简可扩展的终端编码 Agent 外壳——TypeScript 全栈、MIT 开源、作者 Mario Zechner（libGDX 作者）；三身份合一：编码工具、学习教材、开发 SDK。
2. **极简**：上下文窗口稀缺 → 只内置 4 核心工具（read/write/edit/bash）+ 3 辅助（grep/find/ls）；静态系统提示词模板约 90 词，拼入 tools/skills/contextFiles 后 200–400 词（对比 Claude Code 数万字）。
3. **三层架构**：`pi-ai → pi-agent-core → pi-coding-agent`（每层独立可用）；`pi-tui` 是正交 UI 库（仅依赖 get-east-asian-width 和 marked）。
4. **五根杠杆补齐扩展性**：扩展（TS 文件热重载）、技能（渐进式披露）、提示词模板、主题、Pi 包（npm/git 分发，`pi install`）。
5. **模型自由**：`pi-ai` 统一 API（api 字段区分 openai-completions/anthropic-messages/openai-responses 等协议）；`~/.pi/agent/models.json` 启动自动读取，支持 Overrides 与 compat 层。
6. **四种运行模式**：交互 TUI / print-JSON（`pi -p`）/ RPC（stdin/stdout JSON）/ SDK（`createAgentSession()`）。
7. **设计哲学**：做减法即竞争力——MCP 灌 13700+ token 工具描述、弹窗疲劳 → 默认 YOLO，容器化做安全边界。

## 三、验证的关键结论

1. **SDK 三层调用链成立**：`createAgentSession`（sdk.ts:173）→ `Agent.prompt()`（agent.ts:350）→ `runWithLifecycle()`（agent.ts:486）；事件经 subscribe（agent.ts:250）以 AgentEvent 送达，turn_end 在 types.ts:437 带 toolResults。
2. **工具集对账**：tools/index.ts:1-80 导出 read/write/edit/bash + grep/find/ls（外加 powershell）；system-prompt.ts:45 默认仅拼 4 核心，印证"极简"。
3. **pi-tui 解耦实证**：tui/package.json 仅 2 依赖；反向依赖 coding-agent/src/cli/list-models.ts:6 从 pi-tui 引 fuzzyFilter（行号精确命中）。
4. **模型配置机制仍在、API 已重构**：models.json 启动自动读取（sdk.ts:179-180），教程 ModelRegistry.create()（L367）已不存在——本地为 173 行同步门面（model-registry.ts:34），加载/认证下沉 model-runtime.ts。
5. **四种运行模式物理存在**：modes/interactive/、modes/rpc/、print-mode.ts + sdk.ts:173。
