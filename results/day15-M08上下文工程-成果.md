## 一、章节核心要点（两层防护：输入侧 + 历史侧）

**输入侧（防"喂进去就超限"）**
- **M1 工具输出截断**：模型会读文件/跑命令/搜 grep，千行输出直接灌进上下文会瞬间打爆窗口。pi 在工具层按"行数+字节"双上限截断，并在截断处标注 `[Showing lines X-Y of N]` 提示，让 LLM 知道被截掉多少，自行决定是否分次读取。
- **M2 系统提示词"加法式"组装**：把固定骨架 + 工具列表 + guidelines + 项目上下文文件 + Skills 清单拼成一条 system prompt。用 `<project_instructions path=...>` XML 包裹每份上下文文件、`<available_skills>` 只放 skills 的"名称+描述+位置"（懒加载，命中后才让 LLM read 展开）。
- **M3 上下文文件向上递归收集**：不只读当前目录 CLAUDE 类文件，还递归向上收祖先目录的上下文文件，让子目录继承仓库根规范。

**历史侧（防"累积太多"）**
- **M4 Compaction（阈值压缩）**：每次对话推进都统计上下文 token，超过 `contextWindow - reserveTokens` 就触发压缩，把旧消息换成 6 段结构化摘要，腾出窗口但保留关键信息。
- **M5 Branch Summarization（分支摘要）**：agent 可能有多个 branch（会话分支），用 LCA 找出分支公共祖先进行摘要，恢复会话时把分支摘要作为一条系统消息插回，避免分支历史膨胀主上下文。

## 三、验证的关键结论（本地实测）

1. **截断阈值**：`DEFAULT_MAX_LINES=2000`、`DEFAULT_MAX_BYTES=50*1024`、`GREP_MAX_LINE_LENGTH=500`，packages/coding-agent/src/core/tools/truncate.ts:11-13。
2. **`shouldCompact` 阈值**：`return contextTokens > contextWindow - settings.reserveTokens`，且 `!enabled` 直接 false，packages/agent/src/harness/compaction/compaction.ts:246-248。
3. **`shouldCompact` 确切调用链**：`runCheckpoint`（checkpoint.ts:100）→ `prepareCompactionThreshold`（structural.ts:1145）→ `shouldCompact`；命中后转入 `summary.deciding`，发 `compaction_start`（reason:"threshold"）事件，checkpoint.ts:124-158。发生在 run 边界推进、下一条 assistant 生成之前（`continuation.kind==="need_assistant"`）。
4. **溢出压缩用一补**：`prepareOverflowCompaction`（structural.ts:1155），在响应结算事务前为 assistant 预留窗口，对应教程"输出侧 overflow 兜底"。
5. **`buildSystemPrompt` 尾部**：只有 `Current working directory: ${cwd}`（system-prompt.ts:70 与 :165 各一处），**不含 Current date**。全仓 src 检索 "Current date/Today is/current date" 均无命中。

## 四、矛盾 / 漂移 / 疑问

- **「Current date」在本地实现中被移除（关键漂移）**：教程 §四骨架第 8 项（`Current date: 2026-07-03`）、§"末尾加 Current date/cwd"（505 行）都断言 system prompt 尾部有日期。本地 `buildSystemPrompt` 只拼 "Current working directory"。结论：要么教程面向 v0.83（较新）新增、本地 0.85.1 未引入，要么教程记错位置。配套疑问：若需补日期元数据，应加在 `buildSystemPrompt` 尾部（与 cwd 并列），或由 harness 在 `before_run` hook 注入。
- **触发时机命名不同**：教程称 `agent_end` 事件后触发 `shouldCompact`；本地无 `agent_end` 事件符号（grep 0 命中），实际在 `runCheckpoint`/run 边界（一条 assistant 消息完结、下一条待生成的 checkpoint 阶段）触发。语义等价，事件名与触发点结构不同，属版本演化非错误。
- **行号大范围漂移**：resource-loader.ts（85-123 vs 119-156）、skills.ts（335-361 vs 355-383）、replaceUnpairedSurrogates（82→89）等，符号名可对齐。

## 五、一句话总结

Pi 的上下文工程用"输入侧工具截断 + 系统提示词增量组装"与"历史侧 Compaction 阈值压缩 + 分支摘要"两层防线共保窗口，本地 0.85.1 与教程在机制与常量上全部对得上；唯一显眼差异是系统提示词尾部 `Current date` 在本地未实现（疑为 v0.83 新增特性）。
